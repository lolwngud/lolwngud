## 🚀 About Me

전자공학을 전공하며 임베디드 시스템, 제어, 통신, 컴퓨터 구조, 프로그래밍을 폭넓게 학습했습니다.

이후 42 Seoul에서 C 프로그래밍을 집중적으로 경험했고,
Raspberry Pi 기반 내비게이션, UR5e 협동로봇 자동화, 머신러닝 및 데이터 분석 프로젝트를 수행했습니다.

졸업 후에는 약 9개월간 방산 분야에서 IPS 업무를 경험했고,
2026년 10월부터 **AE Korea에서 반도체 장비 엔지니어로 새로운 커리어를 시작합니다.**

현재는 기존의 소프트웨어·전자공학 경험을 바탕으로
**장비 이해, 전기 시스템, 트러블슈팅, 자동화, 데이터 활용 능력**을 강화하는 데 집중하고 있습니다.

> Building on my background in electronics and software,
> I am developing practical expertise in semiconductor equipment engineering.
